# bookbot

BookBot is my first [Boot.dev](https://www.boot.dev) project!

A command-line Python program that analyzes plain-text novels
(word count + alphabetic character count report).

Built as the Boot.dev "Build a BookBot in Python" Guided Project.

## Usage

```
python3 main.py books/frankenstein.txt
```

## Files

- `main.py` - entry point (CLI arguments, report printing)
- - `stats.py` - text statistics helpers
  - - `books/` - download the course-provided .txt books here (frankenstein.txt, mobydick.txt, prideandprejudice.txt)
